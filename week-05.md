## What I Learned

This week was focused on learning how to learn.

I learned that a programmer does not need to memorize everything.
Instead, I should know how to find reliable information, understand documentation, and ask precise questions when I need help.

### My learning process

1. Understand the problem
2. Think about the solution myself
3. Search the documentation
4. Try to solve the problem
5. Ask AI for guidance if necessary
6. Check and understand the answer
7. Implement the solution myself

## Important Rule

> AI is my teammate, not my replacement.
